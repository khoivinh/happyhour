# 2026-08-09 — PRD Track 2 rewritten for iOS

Documentation only. No code changed.

## What happened

`docs/PRD.md` Track 2 ("iOS Native App") was replaced. It had been written around 2026-03, before
most of the current product existed, and had been known-stale for two weeks:
`docs/2026-07-27-ios-app-scoping.md:25-38` audited it, concluded **"anyone starting from Track 2
today would build the wrong app,"** and recommended replacement rather than amendment. That
recommendation was never acted on, because the scoping session's own §0 recorded "no PRD edit" as a
deliberate scope limit. This closes it.

What the old track got wrong, concretely: a **"1500-city dataset from city-timezones"** (it is 30,481
cities in a bespoke interned format), **three appearance modes** (there are four — Happy is
first-class), **min iOS 17** (18 was decided, for `ControlWidget`), an invented folder tree, and
**no mention of App Intents, Shortcuts or Siri at all** — half the value of building native.

87 lines became 277.

## The structural decision

**Track 2 states requirements; the scoping doc keeps the analysis.** The PRD says what must be true;
`2026-07-27-ios-app-scoping.md` keeps why native beats a WKWebView wrapper, what Capacitor costs, and
the day-level estimates. Nothing was copied into both.

That is a direct response to how this went stale in the first place. Two documents restating each
other in different words drift, and only one of them gets updated. The scoping doc was left
**completely untouched** for the same reason.

## Three things the scoping doc could not supply

It was written 2026-07-27; two rounds of work landed after it.

- **The settings model is now split in two, and iOS must not collapse it.** Six preferences sync to
  D1 (zones, 24h, sort, relative time, zone names, theme); three — `share-24h`, `share-zone-abbr`,
  `share-link` — are localStorage-only and deliberately absent from the schema. Board settings and
  share settings have *separate* 24-hour and zone-name toggles with **different defaults**. Merging
  them on iOS would re-create precisely the coupling the 2026-08-08 round existed to break.
- **`CITY_ABBR` joins `ZONE_ABBR` as port-verbatim-with-a-golden-fixture.** 168 curated three-letter
  city names via `shareCityName()`, applied to **share text only** — tiles, preview card and OG image
  stay spelled out. If iOS composes share text without it, the same board shares differently from the
  two platforms. Added as a fifth risk row and a new open question: should iOS compose share text at
  all, or only produce the URL?
- **The share link is `/?z=`, not `/s`.** Track 3's spec still describes a `/s` route and a
  `share.tsx` page that were never built that way. The line Track 2 depends on — the v1.2 Universal
  Link — was corrected, because a Universal Link configured for `/s` would match nothing. The rest of
  that section got a stale-warning banner rather than a rewrite; Track 3 has shipped, so it is history
  now, but history someone might build against.

## Two claims deliberately not made

- **Apple enrollment.** The scoping doc cites `Code/Shotglass/STATUS.md` for org enrollment
  `R63L8BG6UB` being submitted-but-unverified. **That file no longer exists at that path** — the only
  copy I could find is a 2026-07-30 snapshot in the Trash, and `~/Developer/Shotglass` has no
  `STATUS.md` at all. Written as "as of 2026-07-29 … re-confirm before scheduling phases 3 or 6"
  rather than restated as current fact. It gates two phases, so a wrong answer is expensive.
- **Personal Team + App Groups.** Still unresolved, still flagged as a 15-minute empirical test. It
  decides whether widget work can start before the org account activates. Not guessed at.

## Verification

Every `file:line` citation in the new track was mechanically checked against the file it names — 13
of 13 resolve. This mattered more than it sounds: **the scoping doc's own line numbers had already
drifted**. It cites `buildLookup()` at `:244-297` and `migrateOldKeys()` at `:234-269`; inserting the
168-entry `CITY_ABBR` map above them moved both (`:454` and `:255` today). Its *counts* held; its
*locations* did not. Citing a line number is a promise that decays.

Also checked: no figure appears in both documents with different values; the five open questions
survive as questions, none silently answered; and the stale phrases are gone except where the rewrite
quotes them on purpose to say what changed.
